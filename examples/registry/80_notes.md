## random_values

mint_identity: [BEHAVIOR] MUST return the canonical text of a new random UUID on every call, its randomness taken only from the operating system's random source, never from a seeded pseudo-random generator, the clock, a counter or any input; whether the identity is free is left to the writing module, which checks it.
make_secret_value: [BEHAVIOR] MUST draw exactly as many bytes as the imported SECRET_MIN_BYTES constant names from the operating system's random source and MUST return them in a text form a cookie value and an HTML form field carry without escaping, a fresh value on every call.
make_secret_value: [SECURITY_BOUNDARY] MUST take its bytes only from the operating system's random source, never from a seeded pseudo-random generator, and MUST NOT keep, log or put into a diagnostic the value it makes.
equal_in_constant_time: [SECURITY_BOUNDARY] MUST answer whether presented and held are equal using a comparison whose time does not depend on the position of the first differing byte, and MUST answer false, without raising, when their lengths differ.
equal_in_constant_time: [FORBIDDEN_ACTION] MUST NOT keep, log or put into a diagnostic either value it compares.

## given_values

check_request_id_form: [VALIDATION_ERROR] MUST answer a FailedValue with the missing_value member of = models.RefusalKind when request_id is None or holds only white space, and one with the malformed_request_id member when it is not printable text or is longer than the imported REQUEST_ID_MAX_CHARACTERS constant counted in Unicode code points; otherwise it MUST answer a GivenText holding request_id exactly as given.
facts_equal_for_repeat: [BEHAVIOR] MUST answer true only when given and current are of the same facts kind and every field is equal: a required field compared exactly as written, an optional field read through read_optional_text on both sides so that a blank one equals one not given; given and current of different facts kinds MUST answer false.
read_optional_text: [BEHAVIOR] MUST answer None when text is None, empty or white space only, and otherwise MUST answer text exactly as given, neither trimmed nor rewritten.
check_value_forms: [VALIDATION_ERROR] MUST answer one RefusalFailure, carrying the value's path, for every form value outside its form and none for the others, in the order of form_values: the outside_form member of = models.RefusalKind for an alias longer than the imported ALIAS_MAX_CHARACTERS constant counted in Unicode code points, a floor area that is not a decimal number greater than the imported OBJECT_FLOOR_AREA_MIN_EXCLUSIVE constant, a number of rooms that is not a whole number of at least the imported OBJECT_ROOMS_MIN constant, or a floor that is not a whole number; the outside_closed_list member for an object kind outside = models.ObjectKind, a customer language outside = models.CustomerLanguage or a customer kind outside = models.CustomerKind.
check_value_forms: [BEHAVIOR] MUST check only the length of an alias, never its characters, and MUST answer an empty tuple when every form value is within its form; every given value it receives is present, an absent value never reaching it.
read_required_text: [VALIDATION_ERROR] MUST answer a FailedValue with the missing_value member of = models.RefusalKind when text is None, empty or white space only, and otherwise MUST answer a GivenText holding text exactly as given, neither trimmed nor rewritten.

## runtime_settings

load_runtime_settings: [BEHAVIOR] MUST read exactly the environment variables of the case's runtime environment variable table, each into the RuntimeSettings field it targets as given or as None when unset, applying no default and no normalization, and MUST NOT read any other environment variable.
load_runtime_settings: [SECURITY_BOUNDARY] MUST NOT log or put into a diagnostic any value it reads from the environment.

## configuration

load_configuration: [VALIDATION_ERROR] MUST check the settings load_runtime_settings answers in this order and answer a StartDiagnostic at the first check that fails, naming the failed item by its RuntimeSettings field name and never its value, items within one check taken in the order store_path, backup_dir, backup_key, owner_credential, owner_listen, token_presupro, token_client_portal, token_cabinet, token_cabinet_kernel, service_listen: the four tokens and service_listen all set or all unset, a partial set failing on its first unset item; store_path, backup_dir, backup_key, owner_credential and owner_listen each set; each address well formed; the two addresses' ports different; each secret at least the imported SECRET_MIN_BYTES constant in UTF-8 bytes; no two secrets equal; the store and the backup location apart.
load_configuration: [SCHEMA_CONSTRAINT] MUST accept an address only as host:port with no white space and no sign: the host either a dotted-decimal IPv4 address with no leading zero in any part but a lone zero, or a bracketed IPv6 address in its standard text form with no zone identifier and not IPv4-mapped; the port ASCII decimal digits without a leading zero, from the imported LISTEN_PORT_MIN constant to the imported LISTEN_PORT_MAX constant.
load_configuration: [PATH_OR_ARTIFACT_POLICY] MUST compare the store and the backup location by their absolute paths with every symbolic link resolved, a store file that does not exist yet compared as its resolved directory with its name added, and MUST fail naming both items when the paths are equal or one lies inside the other, and naming the item when its path cannot be resolved, a missing directory, a broken link or a loop included; it MUST NOT create, open or remove any file.
load_configuration: [RETURN_SHAPE] MUST answer, when every check passes, a LoadedConfiguration holding the store path and the backup location as given and each listener address as a ListenAddress of its host without brackets and its port as an integer, the service API's address None for an owner-only start; it MUST keep the checked secrets in the module's memory, from which the give functions answer them, and MUST put no secret into its answer.
give_service_tokens: [RETURN_SHAPE] MUST answer one ServiceToken for each member of = models.ServiceName, in the enumeration's order, with the token the last passed load_configuration kept for it, or an empty tuple when that start is owner-only; it MUST NOT read the environment or call load_runtime_settings again.
give_owner_credential: [RETURN_SHAPE] MUST answer the owner credential exactly as the last passed load_configuration kept it, and MUST NOT read the environment or call load_runtime_settings again.
give_backup_key: [RETURN_SHAPE] MUST answer the backup key exactly as the last passed load_configuration kept it, and MUST NOT read the environment or call load_runtime_settings again.
