# State 7 — Registry notes

## random_values

mint_identity: [BEHAVIOR] MUST return the canonical text of a new random UUID on every call, its randomness taken only from the operating system's random source, never from a seeded pseudo-random generator, the clock, a counter or any input; whether the identity is free is left to the writing module, which checks it.
make_secret_value: [BEHAVIOR] MUST draw exactly as many bytes as the imported SECRET_MIN_BYTES constant names from the operating system's random source and MUST return them in a text form a cookie value and an HTML form field carry without escaping, a fresh value on every call.
make_secret_value: [SECURITY_BOUNDARY] MUST take its bytes only from the operating system's random source, never from a seeded pseudo-random generator, and MUST NOT keep, log or put into a diagnostic the value it makes.
equal_in_constant_time: [SECURITY_BOUNDARY] MUST answer whether presented and held are equal using a comparison whose time does not depend on the position of the first differing byte, and MUST answer false, without raising, when their lengths differ.
equal_in_constant_time: [FORBIDDEN_ACTION] MUST NOT keep, log or put into a diagnostic either value it compares.

## runtime_settings

load_configuration: [RETURN_SHAPE] MUST answer, when every check passes, a LoadedConfiguration holding the store path and the backup location as the check of the store and the backup location apart resolved them and each listener address as a ListenAddress of its host without brackets and its port as an integer, the service API's address None for an owner-only start; it MUST keep the checked secrets in the module's memory, from which the give functions answer them, and MUST put no secret into its answer.
load_configuration: [ORCHESTRATION] MUST judge an address item well formed exactly when _parse_listen_address answers a ListenAddress for its text, and MUST put that ListenAddress into its LoadedConfiguration, parsing no address in any other way.
give_service_tokens: [RETURN_SHAPE] MUST answer one ServiceToken for each member of = models.ServiceName, in the enumeration's order, with the token the last passed load_configuration kept for it, or an empty tuple when that start is owner-only; it MUST NOT read the environment or call load_runtime_settings again.
give_owner_credential: [RETURN_SHAPE] MUST answer the owner credential exactly as the last passed load_configuration kept it, and MUST NOT read the environment or call load_runtime_settings again.
give_backup_key: [RETURN_SHAPE] MUST answer the backup key exactly as the last passed load_configuration kept it, and MUST NOT read the environment or call load_runtime_settings again.

_parse_listen_address: [RETURN_SHAPE] MUST answer, for a text in the one address form load_configuration accepts, a ListenAddress of its host without brackets and its port as an integer, and MUST answer None for any other text, raising nothing.
load_configuration: [TEST_EVIDENCE] A test MUST show, for a service token, the owner credential and the backup key each, that a value one UTF-8 byte shorter than the imported SECRET_MIN_BYTES constant answers a StartDiagnostic naming its item and one of exactly that many bytes passes, a value of two-byte characters counted by its bytes and not its characters; that two services with one token answer a StartDiagnostic, and so does each other pair of equal secrets: a token and the owner credential, a token and the backup key, the owner credential and the backup key; and that no StartDiagnostic holds a secret's value.
