## The owner's decisions of 2026-11-17, now in the texts

1. **`PERSONAL_DATA_FIELDS`** is a data-provider table of (answer model,
   field) pairs, with row model `PersonalDataField`.
   - An answer is `personal_data` when one of the listed fields holds a
     value. Otherwise it is `business_confidential`; `open` is never
     answered.
   - The table classifies answers only. The uploaded file is never an
     answer's field.
   - A billing answer without a tax id or legal name, and an anonymised
     project's erased form, are `business_confidential`.
2. **`store.opened_store()`** gives the store `open_store` opened.
   `run_in_transaction` and `read_in_transaction` take that store.
3. **`configuration.give_backup_location()`** gives the backup location to
   `operations`. `NewestBackup`'s three outcomes are each rendered as
   themselves.
4. **The service API's wire format is v1's.**
   - The agent-session header is `SERVICE_AGENT_SESSION_HEADER`
     (`Registry-Agent-Session`).
   - Statuses: `SERVICE_ANSWER_STATUS` 200; `REFUSAL_HTTP_STATUSES` gives
     `not_found` 404, `internal_error` 500 and every other code 422.
   - No `answer_kind` or `view_kind` on the wire; `validate` and `context`
     keep v1's fields (R0-04).
   - Instants are ISO 8601 UTC with `Z`; decimals are strings.
5. **CSRF in forms.** `owner_sessions.give_session_csrf` gives the CSRF value
   to `_render_owner_page`. The sign-in form carries none.
6. **The upload sends CSRF first.** A new module, `upload_framing`, owns the
   multipart framing (owner's choice of a module):
   - `read_upload_head` reads the head, at most
     `UPLOAD_FORM_HEAD_MAX_BYTES` (8192). It answers `UploadHead` with the
     CSRF value, the delimiter and the file part's declared length.
   - `MultipartFileBody` is a `policy` implementation of `UploadBody` over
     the new `external` port `ByteStream`.
   - A19 rule 4 now counts the file part: limit, counting and declared
     length (State 2 change; A21 re-reviewed, no outcome changed).
7. **The session cookie is always `Secure`.** The owner chose this over
   "by listen address" after round-54 found a loopback proxy hole.
8. **An upload arrives once its bounded head has been read** (A13 rule 2,
   owner's choice A over a two-phase admission). Both designs were tested
   in `experiments/registry/upload_framing_proto`. The session check
   reads the clock in one hold of the new session-table lock. That lock is
   innermost and short, in the order import, sign-in, session, table, and
   it guards each session's entry, signed-out mark and last-request
   reading.
9. **Listeners.** HTTP framing of both surfaces is `instance_lifecycle`'s.
   - The body stream ends where HTTP's framing ends it.
   - `LISTENER_READ_TIMEOUT_SECONDS` = 30 is a technical value the author
     chose. It is a per-read progress wait, the socket's own timeout.
   - A request answered before its body was read to the end has its
     connection closed.

## Carried to State 7

  a request body fails before it has a request to hand on (a form, a
