## Исправления

### `registry_a08_withdraw_outside_set_not_found` — исправлен при написании
- Было: сравнение ответов целиком (`==`) с ответом для случайного id.
- Стало: сравниваются код, стадия и виды (`_shape`) и набор полей ответа; путь отказа не сравнивается.
- Основание: State 5 Conventions «Stages»: путь называет запись «by its kind and its id» — id в трёх запросах разный, и полное равенство ответов упало бы и у правильного Registry. A08 rule 7 и A10 rule 3 требуют «того же ответа», что означает код/стадию/виды; см. находку ниже.

### `registry_a08_kernel_publish_names_owner_and_publisher` — усилен при написании
- Добавлена вторая сессия T (мутант M2) и запрос с полем `owner_service` (мутант M4, A08 rule 3 «the caller does not choose it»).

### State 2 от 2026-11-24 (находки свидетелей и судьи, по указанию владельца: матрица защиты данных)
- A10 rule 3 теперь фиксирует «тот же ответ» целиком: код, стадия, вид и путь отказа, путь строится только из запроса (имя входа, никогда id). RT3 `withdraw_outside_set_not_found` сравнивает ответы целиком (`refused_outside == unknown`, `refused_revoked == unknown`) и проверяет, что id указателей в ответе нет; помощник `_shape` удалён. Находка «Путь у `agent_call_refused`» ниже решена в State 2; State 5 Conventions «Stages» нужно выровнять (координатор).
- A08-1 записан целиком, id в последней строке (продолжение раньше уходило к A08-2 — отсюда претензия судьи к RT2 о наборе сессии).

- `not_permitted`/1/`outside_service_rights`: `SERVICE_RIGHTS` даёт `publish_artifact_pointer`/`withdraw_artifact_pointer` только `cabinet_kernel`; A09 rule 3; State 5 closed set.

## Находки
- **Путь у `agent_call_refused`.** State 5 «Stages» велит пути называть запись её id, а A08 rule 7 / A10 rule 3 — «тот же ответ, что для несуществующего». Если путь отказа стадии (2) несёт id указателя или проекта, «тот же ответ» верен только без пути. Тест сравнивает без пути; стоит явно записать в State 5, какой путь у `agent_call_refused` (пустой или поле запроса), чтобы A10 RT1 («identical to that of a random id») и A08 RT3 читались одинаково.
- **`ActingPrincipal.service` у агента.** M07: «the service name when a service» — для `agent_via_kernel` неясно, `None` это или `cabinet_kernel`. Тест его не проверяет.
