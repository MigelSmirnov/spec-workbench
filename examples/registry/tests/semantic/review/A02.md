## Исправления

### `registry_a02_object_characteristic_bounds_checked` — усилен
- Было: только `"0.01"`. Мутант, хранящий площадь как float (или нормализующий Decimal), отвечает `"0.01"` так же и проходил.
- Стало: `"12.50"` должно вернуться как `"12.50"`.
- Основание: A02 rule 2 («kept exactly as written»), Required test 6 («stored as given»), State 6 `Object.floor_area_m2: Decimal`, RUNTIME_SURFACE.md «a Decimal as its text».

### `registry_a02_alias_over_forty_code_points_refused` — усилен при написании
- Вместо только ASCII добавлены астральные символы (ловят UTF-16/байты) и комбинирующие последовательности (ловят графемы и NFC).
- Основание: A02 rule 4 «counted as Unicode code points», A02 rule 2.

### `registry_a02_blank_display_name_refused` — усилен при написании
- Добавлены одновременная пустота имени и адреса (A04 rule 6 «names every one») и исправление (A02 rule 4 «every action that gives the value»).

### State 2 от 2026-11-24 (находки свидетелей и судьи, по указанию владельца: матрица защиты данных)
- A02-1 был определением `missing(v) <=> v absent or strip(v) = ""`. Теперь **A02-1** — только пустая/пробельная ветка (правила 1, 3), **A02-6** — «обязательное значение не задано ⇒ отказ, хранилище не изменилось». A02-4 (комнаты / площадь / этаж) разделён на **A02-4** (комнаты), **A02-7** (площадь), **A02-8** (этаж). Каждая формула — с id в последней строке (продолжение A02-4 раньше уходило к A02-5).
- RT5 `out_of_form_values_all_named`: `Shows A02-7` (тест даёт только площадь; границы комнат и этажа — RT6). RT6 `object_characteristic_bounds_checked`: `Shows A02-3, A02-4, A02-7, A02-8`.
- Новый непомеченный RT8 — `test_required_value_not_given_refused`: проект без имени, комната без имени, Customer без вида и запрос доступа без текста (поле `None`) — `invalid_request`/(4)/`missing_value`, хранилище и сессия без изменений; контроль — заданные значения приняты.

### State 2 от 2026-11-25 (раунд State 2 round-120)
- Правило 1 называет набор пробельных символов: 25 кодовых точек свойства Unicode `White_Space` (T16), импортируемая константа `WHITE_SPACE_CODE_POINTS` (round-121 T4; в замыкании поставщика данных State 6 её ещё нет). Пробелы тестов (`" "`, `"\t"`) в нём; тесты не меняются.
