## Исправления

### `registry_a12_grant_with_replaced_request_version_refused` — исправлен
- Было: замена запроса другим текстом; только `answer_access_request`. Мутанты M1 и M4 проходили.
- Стало: запрос заменяется равным текстом; добавлен прямой `grant_project` со старой версией; строка хранилища снята до первого отказа и сравнивается после обоих.
- Основание: M06 («a new request included, equal text or not»), A12 rules 3, 4; `request_project_access` Observable effect.

### `registry_a12_grant_and_activate_moves_once` — исправлен
- Было: только прямой грант с активацией. Мутант, который двигает версию по числу изменений в `answer_access_request` (снят запрос + проект + активный), проходил.
- Стало: добавлен ответ на запрос с грантом и активацией, и контроль «смена только активного — одно движение».
- Основание: A12 rule 1 («One action moves it once, however many of these it changes»), `answer_access_request` Observable effect («the version moves once for the whole answer»).

### `registry_a12_stale_owner_end_refused_unchanged` — исправлен
- Было: только версия из прошлого. Мутант M2 проходил.
- Стало: добавлена версия `current + 1`.
- Основание: A12-1 (`v != version(x)`), не `v < version(x)`.

## Ожидаемые значения
- `stale`/(5)/`stale_access_version`: State 5 closed set, `REFUSAL_STAGE_VERSION = 5`; Errors `answer_access_request`, `grant_project`, `end_session`.
- Первая версия `ACCESS_VERSION_FIRST = 1`; каждый ход `+1`: A12 rule 1, 60_contracts.md «First ordinals».
- Стирание требует архивного проекта (`refused`/`active` иначе) и снимает проект из всех наборов в той же транзакции, по одному ходу на сессию: `projects.erase_project`, `agent_sessions.drop_project_from_sessions`, R0-61.
- Повторный грант: `changed: false`, `project_joined: false`: `grant_project` Enforces (A05).
