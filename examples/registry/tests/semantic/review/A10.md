## Исправления

### `registry_a10_outside_set_answered_as_not_found` — исправлен
- Было: только сравнение «вне набора» и «случайный id». Мутант, который отвечает незарегистрированной сессии `not_found`/`unknown_session` (стадия 3), проходил, хотя A10-1 требует `registered(x)` и rule 3 — один ответ.
- Стало: добавлен вызов от никогда не зарегистрированной сессии по проекту, который есть в наборе другой сессии; ответ сравнивается с ответом случайного id. Добавлен вызов с токеном Portal и той же сессией (`not_permitted`/1) — конъюнкт «token = Kernel».
- Основание: A10 rules 1, 3; State 5 closed set: `agent_call_refused` — «an unregistered session, a project outside the set, none active … one answer, always of stage (2)».

### Выравнивание по итоговой RUNTIME_SURFACE.md (2026-11-24)
- `validation.get("validation", validation)` заменено чтением голого вида: `validation["exists"] is True` (R0-04). Строки таблицы не меняются.
