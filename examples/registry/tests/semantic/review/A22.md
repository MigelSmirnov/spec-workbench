## Исправления
- При написании RT3 усилен: кроме latest проверяются отзыв и публикация удалённого типа (A22 rule 5, A22-3 — «publish(t) or latest(t)»), иначе мутант M3/M4 проходил бы все тесты A22.
- RT2 усилен контролем после рестарта (`estimate` отклонён, `quote` принят): без него Registry, читающий словарь из хранилища (нарушение rule 2), проходил бы RT2, ведь его списки тоже не меняются.
- Рестарт на другом релизе переведён на вызов `configure_release`, который уже запрошен A01 и A09, вместо собственного `restart_with_release`.
