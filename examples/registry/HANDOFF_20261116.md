## What changed upstream on 2026-11-16, and why

Owner's decisions of the day, each recorded in the texts it touched:

- **Secrets are asked for.** `configuration` keeps the checked secrets and
  gives each only to the module that uses it, which asks:
  `give_service_tokens` (service_access), `give_owner_credential`
  (owner_sessions), `give_backup_key` (backups). `load_configuration`
  answers no secret. An "answer" in A13 rule 7 and A17 rule 6 is what Registry
  gives a service or the owner; a value one module returns to another is not
  one (State 3 "Secrets never leave", State 5 conventions). State 2 unchanged.
- **The clock is system_clock_backend v6** (added to the Factory, code-factory
  #221, spec-workbench #187): `recorded_now` returns a timezone-aware UTC
  `datetime`, `monotonic_reading` an `int` of nanoseconds; `clock.today_in_utc`
  removed — `operations` takes an action's today as the UTC date of its one
  instant (`_today_of`).
- **`store_persistence`**, the store's companion that only `store` calls
  (cabinet-kernel's precedent), holds the SQLite repository; `store` keeps the
  connection, the transaction, row placement and every list's order.
- **`delete_by`** was added to persistence_backend v3 (code-factory #222,
  spec-workbench #189) so erasures stay deterministic.
- **Question-round closure** (spec-workbench #188): a contradiction closes on
  every unit it names once one of its quotes no longer stands in the texts and
  a round of the state followed.

## State 6 choices made by the author (owner's delegation of 2026-11-11)

Recorded with their reasons in `60_contracts.md`; worth a look before notes
build on them:

- A refusal is a value (a discriminated union of a result and `Refusal`), not
  an exception; `operations` answers one `OperationAnswer` union.
- Steps are ports (`TransactionStep`, `OwnerStep`), the transaction is
  `StoreTransaction`, the store the `RegistryStore` class.
- Formats: the service API's JSON wire format with the agent session in the
  `Registry-Agent-Session` header; the import file's JSON shape (R0-72); the
  backup file — a record line readable without the key, then AES-256-GCM under
  an HKDF-SHA256 key (`cryptography` package, pinned by digest under A20), the
  key digest over `BACKUP_KEY_DIGEST_DOMAIN`.
