# State 7 bounded repair — Flow 5 Holded publication generation obligations

request_holded_publication: [ORCHESTRATION] Persist the logical publication attempt and exact immutable Invoice Card revision binding before the one permitted create mutation; a technical create response never by itself settles Cabinet publication success.
request_holded_publication: [ORCHESTRATION] When create_holded_purchase returns a clear canonical documentId, obtain read-only evidence for that exact Holded document through the existing Holded gateway read operation and perform complete A51 business verification before returning a successful logical publication.
request_holded_publication: [BEHAVIOR] Complete A51 verification must preserve and compare supplier identity/name, supplier invoice number, date, currency, line count and order, line names, quantities, tax rates, and final gross total within accepted currency precision; Holded intermediate rounding differences may be preserved without failure only under the accepted A51 rules.
request_holded_publication: [RETURN_SHAPE] A clear create followed by GET/read failure returns the publication in reconciliation_required, a business-field mismatch returns it in payload_mismatch, an ambiguous create returns it in outcome_unknown, a rejected create returns it in failed, and a verified read-back returns it in verified with external_document_id; none of these raise, none authorize another automatic POST, and none rewrite Invoice Card facts.
request_holded_publication: [BEHAVIOR] Store Holded numeric status as raw external evidence only; do not infer draft, approved, paid, posted, cancelled, or other accounting meaning.
reconcile_holded_publication: [ORCHESTRATION] After an ambiguous create outcome, perform only read-only marker recovery; zero matches remain outcome-unknown, multiple exact matches remain duplicate conflict, and one exact marker candidate must be GET-read and completely A51-verified before settlement.
reconcile_holded_publication: [BEHAVIOR] An exact attempt-marker match is correlation evidence only and must never settle a publication without complete business verification against the stored exact attempt and Invoice Card revision.
