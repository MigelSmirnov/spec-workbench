- next_store_position: [RETURN_SHAPE] Returns the new store position as a positive int, greater than every position assigned before.
- open_store: [BEHAVIOR] MUST run, in this order, stopping at the first failure: take an exclusive non-blocking lock on data_directory itself, opened as a directory without following links and held for the life of the process, so the lock creates no file; check that data_directory and everything inside it are owned by the process's effective user and grant no permission to group or others; walk the directory without following links and find no symbolic link; then open the database file inside data_directory as the module's one SQLite connection with synchronous FULL, after os.lstat finds that path no symbolic link; create its tables with create_store_schema, which leaves existing tables as they are; then remove the module's own temporary files left by an interrupted publish and every file of the content-addressed area whose digest no StoredValue names — a trial case's file fixture is itself a StoredValue of file carriage (M21), so no other record names a value file —, which is a digest for which list_stored_value_rows_by_value_digest answers no row, and create the content-addressed area and the spool area when absent.

- open_store: [PATH_OR_ARTIFACT_POLICY] MUST keep the content-addressed area as the directory named by the imported STORE_VALUE_AREA_DIRECTORY constant directly inside data_directory, a value's bytes in the file named by its value_digest directly inside that area, and the spool area as the directory named by the imported STORE_SPOOL_AREA_DIRECTORY constant directly inside data_directory, each run's spool directory named by its run_id directly inside the spool area (decision 25).
- open_store: [VALIDATION_ERROR] MUST raise RefusedError whose reason names the failed check: data_directory does not exist (it is never created here), lock held by another process, directory not private (naming the first offending path), or symbolic link found (naming its path); it removes and creates nothing when a check fails.
- open_store: [RETURN_SHAPE] Returns StoreOpened with data_directory and temporary_files_removed, the count of temporary files removed, unnamed value files not counted; no record, named value file or spool is removed by this call; the spools of ended runs are removed later in the start sequence, by run recovery (A18 rule 4).

- page_records: [BEHAVIOR] MUST read the rows of record_type in store order through StoreRepository and never ask the database for a limit, a range or a set condition: with no filter the type's whole list (list_slot_rows for slots, list_run_rows for runs, and so for each of the fourteen types list_records lists, decision 20 — activation, flow_activation, stored_value and spooled_file are never paged, have no whole list and no find at a position, and as record_type raise InvalidRequestError before any read); with an equals filter the type's equality list of the named field (list_run_rows_by_status, list_node_execution_rows_by_run_id, and for node executions list_node_execution_rows_by_executed_implementation_id for executed_implementation and list_node_execution_rows_by_executed_binding_id for executed_binding), a status value passed as the member of the type's status enumeration; with an in_set filter one such list per value, merged by store_position without repeating a row; it then reverses that order, keeps the rows whose store_position is below the token's position, and returns the records of the first page_size of them.
- page_records: [DETERMINISM_OR_ORDERING] With a continuation_token MUST return only records strictly below the store position decode_continuation_token gives for the same record_type and record_filter, so a record written meanwhile, having a higher position, never shifts, repeats or hides an item; the filter is evaluated on the records as they are at this call, so a record whose filtered field changed since an earlier page is judged by its current value; page_size may differ between pages.

- page_records: [RETURN_SHAPE] Returns RecordPage whose records holds up to page_size records in the RecordSet field of their type, and whose continuation_token is encode_continuation_token of the last returned record's position when more matching records remain below it, otherwise None.
