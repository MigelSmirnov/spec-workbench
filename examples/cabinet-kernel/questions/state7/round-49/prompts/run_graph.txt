- plan_run: [DETERMINISM_OR_ORDERING] A function element's conclusion is its latest NodeExecution's status: succeeded concludes succeeded, contract_violation, sandbox_violation, timeout, resource_exhausted and crashed conclude failed; an operation element's is operation_element_conclusion of its element under the context — ElementFailed is failed whatever its status, ElementWaiting waits and its dependants wait, ElementNotReached is not concluded; an operation element is judged by that answer alone, not by its NodeExecution status, which stays outcome_unknown after the owner's resolution; a skipped_by_guard or upstream_failed record concludes its node so; a run with any refused_by_owner NodeExecution has status refused and no next node. Records written together are sorted by (node_id, map_index) with an absent map_index before index 0, identifiers compared by Unicode code point.
- plan_run: [DETERMINISM_OR_ORDERING] The next node is the ready node with the smallest node_id; a node is ready when every input port holds its value: flow inputs delivered along every edge from them — a flow input or output endpoint is the node_id empty string (A05 rule 2) —, constants to their port — a FlowConstant's value is the value_id composition wrote —, and outputs of a concluded succeeded node along every enabled edge. A mapped node, once selected, takes its elements in list order, every element that has no concluded record and does not wait; a node none of whose elements without a concluded record can execute is not ready, so the next ready node is selected among the others; a waiting or failed element does not stop the elements after it, and a concluded element is never taken again.
- plan_run: [BEHAVIOR] An edge with no guard is enabled once its source concluded succeeded; a guarded edge is decided only once its source node concluded succeeded, from that same source node's output on the edge's guard_port (M15), enabled when that value's canonical JSON text equals guard_value and disabled otherwise; an edge whose source has not concluded is undecided, so a port with such an edge can still receive a value. A node one of whose input ports can no longer receive a value because every edge into that port is disabled or comes from a skipped node concludes skipped_by_guard, even when its other input ports receive theirs (A13 rule 4 is per input port); a node with an input from a failed or upstream_failed node concludes upstream_failed, which wins over skipped_by_guard. Such drafts have no executed, no map_index unless an element of the node already ran, and are derived only from records already written.
- plan_run: [BEHAVIOR] A mapped node's elements are the positions of the list delivered to its map_over port, counted from the JSON array its StoredValue holds — read with read_value_bytes, or the canonical_json of an AssembledList not yet written — or the files of its SpooledFilesRef; a mapped node over an empty list is ready with over_empty_list and one element without map_index whose sources are the node's inputs; a mapped node concludes only when every element concluded, succeeded only when all succeeded. For a succeeded mapped node with elements, the lists an edge takes to a node or a flow output are asked of assemble_mapped_lists, an output no edge takes being asked nothing: ListsOverCeiling makes the node failed for its dependants, which conclude upstream_failed, with no record of its own and every element record staying as it is.
- plan_run: [BEHAVIOR] Each element's sources are one per input port in port name order: a RecordedSource for a flow input's StoredValuesRef, a constant's StoredValuesRef or the output ref of an unmapped succeeded node on the enabled edge — from its NodeExecution or its ElementSucceeded outputs —; a MappedListSource with the AssembledList of a mapped node's output; a ListElementSource with the list's own source and the element's map_index for a mapped element's map_over port. A guard's source node is never mapped (flows' proof), so a guard reads a written StoredValue. A flow output's source is formed the same way; an output reached by an edge straight from a flow input is that input's StoredValuesRef (A13 rule 3).
- plan_run: [BEHAVIOR] When nothing is derived and no node is ready, the status is: when any element waits, awaiting_approval if one waits with reason owner_approval and otherwise pending, with one WaitingPoint per waiting element — a mapped operation node's elements being the positions of its delivered list; when nothing waits, succeeded when every node concluded succeeded or skipped_by_guard and failed otherwise, a mapped node whose delivered list is over the ceiling counting as failed. While a draft is derived or a node is ready the status is running. The outputs are those produced so far, whatever the status (A13 rule 7), each named by its flow output port; once the status has ended (= models.RunStatus: succeeded, failed or refused here) every other flow output is a MissingOutput with reason skipped_by_guard when every edge into it was disabled or comes from a node concluded skipped_by_guard and not_produced otherwise (= models.OutputReason).
- plan_run: [RETURN_SHAPE] Returns RunPlan with every element's ElementState in (node_id, map_index) order, every edge's EdgeState in the flow version's edge order, the derived drafts, the next ReadyNode or None, the waiting points in (node_id, map_index) order, the produced outputs and missing outputs in flow output port name order, and the status.
