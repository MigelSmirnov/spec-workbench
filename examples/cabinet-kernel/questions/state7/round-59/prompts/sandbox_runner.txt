A replacement is installed in one of two ways, chosen for every path of every list by the object the path names before its last dot: when that object is a class (isinstance of type) — datetime.datetime.now, datetime.datetime.utcnow, datetime.datetime.today and datetime.date.today, and the trapped class's methods — the method is trapped as a method, otherwise the module attribute is; an attribute of a module is replaced with setattr on that module; a method of a class or of a built-in type is replaced by setting, on the class's module, the class's name to a subclass that defines the trapping method, since the __dict__ of a type is read-only and is never written.
- runner_source: [BEHAVIOR] process_count bounds the code's tasks alive at once: the main thread counts as the first, every live thread and every process forked with os.fork counts with its threads, bubblewrap's own processes do not count. - runner_source: [BEHAVIOR] The program MUST load the code file as a module and call its top-level run once with a dict holding one entry per input port, read from the files its configuration names: a value port has exactly one file, its JSON decoded to Python — for cardinality many that file holds the JSON array, which decodes to the list itself and is never wrapped in another —; a file port of cardinality one its one file's bytes; a file port of cardinality many a list of its files' bytes in order; it writes a crashed message, with the type and message of the exception when one escaped, when the module fails to load, has no run, or run raises. - runner_source: [BEHAVIOR] When run returned, the program MUST write one returned message: whether the value is a dict with only str keys and, for each key, its form — json for a value port whose value json.dumps accepts with sort_keys=True, separators (',', ':'), ensure_ascii=False and allow_nan=False (for a many value port, a list), file for a file port whose value is bytes, file_list for a many file port whose value is a list of bytes, not_representable otherwise and for a key that is no output port. It writes nothing to standard output or standard error.
