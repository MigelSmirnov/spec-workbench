## Исправления

### `kernel_a05_exclusive_guards_share_input_port` — исправлен
- Было: проверялись два охраняемых ребра на одном порту `check.verdict` со значениями `new`/`duplicate` (доказано) и те же рёбра без охран (отказ). Мутант «рёбра исключают друг друга, если оба охраняемы и значения различаются», не сравнивающий порт охраны и узел-источник, проходил этот тест и `kernel_a05_same_guard_value_edges_refused`.
- Стало: `_check_contract` вынесен, у `check_step` добавлен второй выход-закрытое множество `kind`; `_guard_flow` принимает `guard_ports`. Два контроля: охраны `verdict`/`kind` одного узла и охраны `verdict` двух разных узлов `check`/`check2` → `fan_in` в `save.x`. Оба мутанта падают на `proven is False`.
- Основание: A05 rule 3 «Two edges into one port can both deliver unless both are guarded on the same guard port of the same source node with different guard values»; формальный инвариант `can_both_deliver`.

### `kernel_a05_highest_effect_class_max_or_read` — исправлен
- Было: `both` с узлами `lookup` (`read`) и `save` (`draft-write`). Мутант «класс последнего операционного узла по `node_id`» давал `draft-write` и проходил.
- Стало: добавлена версия `swapped` с теми же привязками и узлами `a_save`, `b_lookup` — `draft-write` идёт первым; ожидается `draft-write`. Вместе с `both` ловятся и «первый», и «последний» узел.
- Основание: A05 rule 5 «the highest effect class among the version's operation nodes in the order of M10»; инвариант `highest_effect_class = max(operation_nodes.effect_class) OR read`.
