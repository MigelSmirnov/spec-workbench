# financial_policy

FinancialValidationError.__init__: [VALIDATION_ERROR] MUST represent an R9 rejection without implicit conversion or replacement values.
validate_eur_amount: [VALIDATION_ERROR] MUST reject an amount whose currency is not the single portal currency or whose sign is not allowed, and MUST return the accepted amount as a Decimal quantized by the portal money quantization, without any currency conversion.
calculate_completed_work: [BEHAVIOR] MUST compute each section's completed work as its planned work multiplied by its completion percent and divided by one hundred, quantize each per-section result by the portal money quantization, and MUST NOT use float arithmetic.
calculate_overall_progress: [BEHAVIOR] MUST use the weighted R9 formula over positive work_planned and return None when its denominator is zero; MUST NOT use arithmetic mean or fabricate zero. ProgressSectionView.completion_percent is optional, and a section whose completion_percent is None has no reported progress: it MUST contribute to neither the numerator nor the denominator, and MUST NOT be read as zero, because an unreported section is not a section reported as unstarted.
calculate_material_balance: [BEHAVIOR] MUST return quantized material_planned minus material_actual, preserving a negative overspend result without clamping.
calculate_work_balance: [BEHAVIOR] MUST return quantized completed_work_total minus payments_total and the label the sign of that difference selects: WorkBalanceLabel.COMPLETED_AHEAD_OF_PAYMENTS when it is positive, WorkBalanceLabel.UNUSED_ADVANCE_PAYMENT when it is negative, WorkBalanceLabel.BALANCED when it is zero.
_quantize_money: [BEHAVIOR] MUST quantize the Decimal to the portal money fraction digits with the portal money rounding mode and MUST NOT convert through float.
