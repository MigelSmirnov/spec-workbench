It MUST return None for a value whose scheme is neither http nor https, and for a value carrying userinfo, a query, a fragment, a non-empty path other than a single trailing slash, or a missing scheme or host. The returned canonical origin MUST discriminate: two values differing in scheme or in host after that lowercasing, differing by any additional host prefix, differing by any additional host suffix, or differing in effective port MUST each receive a different canonical origin. A None result MUST NOT be treated as equal to any value, including another None result.

The supplied now and every timestamp it stores are readings of one monotonic clock that cannot move backwards, so the window is a duration measured on that scale and never a wall-clock interval. Each bucket holds at most the allowed attempts, because a refused attempt is not recorded, and it MUST keep total memory bounded by pruning buckets that hold no attempt inside the window, and MUST NOT distinguish its refusal by account state, by whether a capability exists, or by any other fact about the presented credential.
- _requires_no_store: [BEHAVIOR] MUST return true for exactly the canonical paths of the imported NO_STORE_PATHS constant, compared as whole paths and never as an abbreviation or a prefix of them. - _transport_log_record: [SECURITY_BOUNDARY] MUST return the four values under the labels of the imported TRANSPORT_LOG_LABELS constant, in its order: the request id, the method, the canonical_path argument and the status, each written as its label, an equals sign and the value, and joined by single spaces. Headers, cookies, query values, bodies, the authenticated principal's identity, raw exception text and configuration values MUST NOT be added to the record; no portal route carries a credential in its path.
- install_transport_guards: [ORCHESTRATION] MUST register exactly one FastAPI http middleware on the supplied application. For every request the middleware MUST evaluate the checks below in the order they are written, and the order is a pipeline rather than a choice between alternatives: each check either produces the response named for it and ends the request there, or leaves the request untouched for the next check to evaluate. A check that does not produce a response MUST NOT call the next handler, MUST NOT return, and MUST NOT cause any later check to be skipped; the next handler is called exactly once, after every check in the list has left the request unrefused. The status of each response a check produces is the status_code of the row of the imported TRANSPORT_GUARD_STATUSES constant selected by the = models.TransportGuardRefusal member named in parentheses. The checks are: derive a request id carrying no identity or credential material; reject the request (UNTRUSTED_HOST) when _host_allowed refuses the request host against the trusted_hosts field of the settings; answer an OPTIONS request carrying an Origin listed in the allowed_origins field of the settings with a preflight (ALLOWED_PREFLIGHT) echoing the requested method and headers plus Vary Origin, together with the allow-origin and allow-credentials headers every allowed-origin response carries, and reject an unlisted origin (UNLISTED_PREFLIGHT_ORIGIN); reject POST on the canonical viewer logout path, the imported VIEWER_LOGOUT_PATH constant, (LOGOUT_ORIGIN_MISMATCH) unless _normalized_origin of the request Origin equals _normalized_origin of the public_origin field of the settings; reject (OVERSIZED_BODY) when _body_within_limit refuses the declared Content-Length against the max_request_body_bytes field of the settings; reject (RATE_LIMITED) when _record_viewer_entry_attempt refuses a POST on the canonical viewer entry path, the imported VIEWER_ENTRY_PATH constant, keyed by _client_bucket_key, before any credential parsing or verification. When the production_logging field of the settings is true it MUST emit exactly one INFO record per completed request, built only by _transport_log_record. It MUST classify every path through _canonical_path so a deployment-prefixed path is treated exactly like its stripped inner path, keep its rate-limit state bounded inside the installed guard, and MUST NOT authenticate a principal, read persistence, import a domain or application module, or import starlette directly.
