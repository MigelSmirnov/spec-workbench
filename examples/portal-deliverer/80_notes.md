# State 7 — Portal Deliverer notes

## deliverer_api

bearer_credential: [SECURITY_BOUNDARY] MUST return the token part of the request's single Authorization header whose value is the scheme Bearer, compared without regard to case, followed by exactly one space and a non-empty token, and MUST raise AuthenticationRequired when the header is absent, appears more than once, or has any other form; it MUST NOT read the body or the path parameters.
check_token: [SECURITY_BOUNDARY] MUST compare the presented credential with the service token whole, case-sensitively and in constant time with hmac.compare_digest over their UTF-8 bytes, return None when they are equal, and raise AuthenticationRequired otherwise; a matching token authorizes the one principal of the service, the calling flow of the owner, for every confirmed connection, and it MUST NOT log or return either value.
_project_id: [VALIDATION_ERROR] MUST return the UUID the text spells only when the text is the canonical spelling of that UUID, lowercase hexadecimal digits in groups joined by hyphens exactly as str of the parsed UUID writes it, and MUST raise DelivererError with the INVALID_REQUEST member of = models.RefusalCode for any other text, including an uppercase, braced, URN or unhyphenated spelling.
_refusal_row: [BEHAVIOR] MUST return the one row of the imported REFUSAL_ANSWERS constant whose code equals the given = models.RefusalCode member; the table is total, so every member has exactly one row.
_refusal_answer: [RETURN_SHAPE] MUST answer with a JSONResponse whose status is the status of the row _refusal_row returns for the code and whose body is the JSON form of a Refusal carrying that code and the detail of the same row, and nothing else.
_deliver_request: [VALIDATION_ERROR] MUST return a DeliverRequest only when the body is UTF-8 JSON holding one object with exactly the fields name and source_id, both strings, and MUST raise DelivererError with the INVALID_REQUEST member of = models.RefusalCode for an empty body, bytes that are not UTF-8 or JSON, another JSON type, a missing or extra field, or a field that is not a string; it MUST NOT check the form of source_id, which photo_delivery decides.
_published_request: [VALIDATION_ERROR] MUST return a PublishedRequest only when the body is UTF-8 JSON holding one object with exactly the field photo_id, a string in the canonical lowercase hyphenated spelling of a UUID as _project_id accepts it, and MUST raise DelivererError with the INVALID_REQUEST member of = models.RefusalCode for any other body.
scan_route: [ORCHESTRATION] MUST call check_token with the token held in the application state and the credential bearer_credential takes from the request, then _project_id with the path project id, then the imported scan_project_photos with the context held in the application state, and MUST answer with a JSONResponse holding the JSON form of the ScanResult it returns and its default success status; AuthenticationRequired MUST be answered by _refusal_answer with the UNAUTHORIZED member of = models.RefusalCode and DelivererError by _refusal_answer with the code it carries. It is a plain function, so the framework runs it in its thread pool, and it MUST NOT read the body.
deliver_route: [ORCHESTRATION] MUST be defined async, check the token as scan_route does before anything else, then await the request body once and pass it to _deliver_request and the path project id to _project_id, then run the imported deliver_project_photo with the context held in the application state and the name and source_id of the request through starlette run_in_threadpool, because the project lock it takes waits without a time limit, and MUST answer with a JSONResponse holding the JSON form of the PlacementOutcome it returns and its default success status, whatever its status; AuthenticationRequired and DelivererError MUST be answered as in scan_route.
mark_route: [ORCHESTRATION] MUST be defined async, check the token as scan_route does before anything else, then await the request body once and pass it to _published_request and the path project id to _project_id, then run the imported mark_photo_published with the context held in the application state, the path source id unchanged and the photo_id of the request through starlette run_in_threadpool, and MUST answer with a JSONResponse holding the JSON form of the MarkOutcome it returns and its default success status; AuthenticationRequired and DelivererError MUST be answered as in scan_route.
answer_health: [RETURN_SHAPE] MUST return a HealthAnswer whose status is the OK member of = models.HealthStatus and nothing else; it reads no file, setting, token or project and raises nothing.

## runtime_settings

load_runtime_settings: [VALIDATION_ERROR] MUST read every variable of the runtime environment variable table once from the process environment, normalise it, apply the default its row declares for the environment field when it is absent and validate it exactly as its row declares, and return RuntimeSettings with each value in the field its row targets; a required variable that is absent or a value of the wrong form MUST raise ValueError that names the variable and never its value, and it MUST NOT read a file or log a raw value.

## deliverer_service

read_token: [SECURITY_BOUNDARY] MUST open the last component of path once without following a link, resolving the folders above it as they stand, and judge only that opened file: it MUST raise ValueError when the opening fails or meets a link, when the opened file is not a regular file, when its mode gives the group or others any permission, when its content is not UTF-8, or when what remains after removing the characters of the imported TOKEN_TRIM_CHARACTERS constant at both ends, and no other character, is shorter than the imported TOKEN_MIN_LENGTH constant or holds a character outside visible ASCII, exclamation mark to tilde; otherwise it MUST return that remaining text. No message, log line or exception it raises MAY carry the content of the file.
load_config: [VALIDATION_ERROR] MUST raise ValueError when the port of the settings is above the largest TCP port number or when zoneinfo does not know their timezone, then MUST call the imported load_connections once with the connections_file of the settings as a Path, letting its DelivererError end the start, and MUST return DeliveryContext with binary_root, state_dir and connections_file of the settings as Path values and their timezone unchanged; it MUST NOT read the credential file.
run_service: [ORCHESTRATION] MUST call load_runtime_settings, then load_config with those settings, then read_token with the credential_file of the settings as a Path, then the imported create_app with that context and token, in that order, and serve the application with uvicorn on the loopback interface and the port of the settings, with forwarded and proxy headers not trusted; a failure of any of these steps before listening MUST write one line naming the failed step to standard error, never the token, and return the exit status one, a stop by a signal after serving MUST return the exit status zero, and a failure of the web server after it listened MUST return a non-zero exit status.

## object_connections

_subfolder: [VALIDATION_ERROR] MUST return the value unchanged only when it is a string holding a relative path that is not absolute, has no .. segment and still names a folder below the root once its empty and . segments are removed, and MUST raise ValueError for any other value, so a subfolder never names the root itself or a place outside it by its written form.
confirmed_connection: [VALIDATION_ERROR] MUST call load_connections exactly once with connections_file and decide only from that reading, in this order: its DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode passes on unchanged; a reading with no record for project_id MUST raise DelivererError with the UNKNOWN_PROJECT member; a record whose assignment_confirmed is false MUST raise DelivererError with the CONNECTION_NOT_CONFIRMED member; otherwise it MUST return that ObjectConnection. It MUST NOT consult any folder.
available_photo_folder: [PATH_OR_ARTIFACT_POLICY] MUST resolve the root of the connection strictly, following its links, and the photo_subfolder joined to that resolved root strictly, and MUST return the resolved photo folder only when both exist as folders and the resolved photo folder lies strictly below the resolved root; a missing root or folder, one that is not a folder, a loop of links, any OSError or RuntimeError of resolving or inspecting, or a photo folder equal to or outside the resolved root MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode. It MUST NOT list the folder or touch the invoice_subfolder.
_connections_file: [VALIDATION_ERROR] MUST decode content as UTF-8 JSON, with an object_pairs_hook of json.loads that rejects a member name repeated within one object anywhere in the file, and return it validated strictly against = models.ConnectionsFile: one object whose only field is objects, each key of objects the canonical lowercase hyphenated spelling of a UUID, equal to the str of the UUID it parses to, and each value a ConnectionEntry with exactly its fields, each of its declared type without coercion; it MUST raise ValueError for any other content.
load_connections: [VALIDATION_ERROR] MUST read the file at path once and judge it whole before any project is looked up: a file that is absent or cannot be read, a ValueError of _connections_file for its bytes, or a ValueError of _subfolder for the photo_subfolder or invoice_subfolder of any entry MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode; otherwise it MUST return a dict from the UUID of each key to an ObjectConnection with that project_id and the fields of its ConnectionEntry.

## source_folder

_is_ignored: [PATH_OR_ARTIFACT_POLICY] MUST return True when the name, with only the letters A to Z lowered and no other character changed, begins with an item of the imported IGNORED_NAME_PREFIXES constant, ends with an item of the imported IGNORED_NAME_SUFFIXES constant, or contains the imported CONFLICT_COPY_MARK constant, and False otherwise; it MUST NOT use str.lower or casefold, which change letters beyond A to Z.
_opened_folder: [PATH_OR_ARTIFACT_POLICY] MUST be a contextlib.contextmanager generator that opens the absolute path one folder at a time from the root of the file system, each folder opened with os.open in the one before it through dir_fd with O_DIRECTORY and O_NOFOLLOW, yields the descriptor of the last folder and closes every descriptor it opened on every exit; an opening that fails for any reason, a symbolic link or an object that is not a folder among them, MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode.
_unlisted_folder: [VALIDATION_ERROR] MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode chained from the given OSError and MUST never return; it is the one place a folder that cannot be listed or opened during a scan becomes a refusal.
_modified_at: [FIELD_ASSIGNMENT] MUST return the st_mtime_ns of info as a naive datetime in UTC with microsecond precision, dropping any finer fraction toward the earlier instant, also before the epoch, and MUST NOT go through the float st_mtime or the local time zone.
_read_source_bytes: [VALIDATION_ERROR] MUST open entry once in the folder descriptor with os.open through dir_fd, for reading only, in non-blocking mode and without following a link, take one os.fstat of the opened descriptor before reading, and raise Rejected with the NOT_A_REGULAR_FILE member of = models.PlacementFailure when that object is not a regular file, or with the UNREADABLE_FILE member when the opening, that fstat or a read fails; otherwise it MUST read in one pass from the start, continuing after short reads, until the end of the file or one byte past the imported MAX_SOURCE_BYTES constant, raise Rejected with the TOO_LARGE member when that byte is reached, and return the bytes read with that fstat result; the descriptor MUST be closed on every path and the file never opened again.
_source_files: [DETERMINISM_OR_ORDERING] MUST list the folder descriptor once with os.listdir, skip every name _is_ignored accepts, take one os.stat of each remaining entry in that folder with follow_symlinks False, skip an entry that disappeared and every entry that is neither a regular file nor a folder, call _unlisted_folder for a listing or reading that fails otherwise, then yield the folder descriptor, the entry, its name relative to the photo folder joined by slashes and its stat result for each regular file in Unicode code point order of the entries, and only then enter each folder entry in the same order; a folder entry is opened with os.open, O_DIRECTORY and O_NOFOLLOW through dir_fd, skipped when that opening meets a symbolic link or an object that is not a folder, refused through _unlisted_folder when it is gone or fails otherwise, walked the same way and closed when its walk ends.
observe_source_files: [ORCHESTRATION] MUST open the folder with _opened_folder, call _observed once for each file _source_files yields from that descriptor, and return the SourceFile of each in the order _source_files yields them, keeping no bytes; a DelivererError of the walk MUST pass on, so a partial scan is never returned, and it MUST NOT create, change, move or delete anything in the folder.
_name_parts: [VALIDATION_ERROR] MUST return the segments of the name split on the slash character only when the name is non-empty and every segment is non-empty, is neither . nor .. and is not one _is_ignored accepts, compared exactly without Unicode normalisation, and MUST return None for any other name, an absolute name among them.
read_named_source: [PATH_OR_ARTIFACT_POLICY] MUST return None, opening nothing in the folder, when _name_parts returns None; otherwise it MUST open the folder with _opened_folder, then each folder segment of the name in the one before it with os.open, O_DIRECTORY and O_NOFOLLOW through dir_fd, and take one os.stat of the last segment in the last folder with follow_symlinks False, and MUST return None when an opening or that reading fails, the DelivererError of _opened_folder among them, or the last segment is not a regular file; otherwise it MUST return a SourceRead holding the SourceFile and bytes _observed gives for that last segment, its folder descriptor, the name and that reading, closing every descriptor it opened.
_signature_format: [BEHAVIOR] MUST return the first format of the imported SOURCE_FORMATS constant, in its order, for which every row of the imported SOURCE_SIGNATURES constant whose format equals it finds the bytes its signature spells in hexadecimal at its offset from the start of content, and None when no format does; it reads only content.
_observed: [VALIDATION_ERROR] MUST judge the rejection orders of A1 in their order: a listed st_size of info of zero is rejected with the EMPTY member of = models.ObservationReason and one above the imported MAX_SOURCE_BYTES constant with TOO_LARGE, both before the file is opened; then it MUST call _read_source_bytes once, and a Rejected it raises is rejected with the ObservationReason member whose value equals that reason, no bytes read is EMPTY, and _signature_format returning None is UNSUPPORTED_FORMAT. A rejected SourceFile carries the given name, the listed size, the time _modified_at gives for info, no source id and no bytes; otherwise it MUST return a READY SourceFile with the hashlib.sha256 hexdigest of the bytes as source_id, their length as size and the time _modified_at gives for the fstat result of the read, together with those bytes.

## photo_preparation

_to_naive_utc: [FIELD_ASSIGNMENT] MUST return the same instant as the given aware datetime, converted to UTC with its tzinfo removed and its microseconds kept, and MUST raise ValueError for a naive datetime, which names no instant.
_photo_moment: [BEHAVIOR] MUST read the EXIF of the first frame once with Image.getexif, take ExifTags.Base.DateTimeOriginal and ExifTags.Base.OffsetTimeOriginal from its ExifTags.IFD.Exif directory and ExifTags.Base.DateTime from its first directory, a reading that fails counting as no EXIF, and return the first moment _parse_exif_moment gives for DateTimeOriginal with OffsetTimeOriginal, then for DateTime with no offset, each read in zone and judged against modified, paired with the EXIF member of = models.DateSource; when neither gives one it MUST return modified unchanged with the FILE_MODIFIED member. It MUST NOT read the service clock.
build_publication: [FIELD_ASSIGNMENT] MUST return a PhotoPublication whose intake_id is the imported INTAKE_ID_PREFIX constant followed by the canonical project id, a hyphen and the source id, whose project_id and file_ref are the given ones, whose photo_date is the taken_at of photo unchanged, whose intake_source is the imported INTAKE_SOURCE constant, whose client_visible is false and whose section_id and caption are None; it reads nothing and writes nothing.
_camera_offset: [VALIDATION_ERROR] MUST return the datetime.timezone of the offset only when it is a string of a plus or minus sign, two digits of hours not above the imported CAMERA_OFFSET_MAX_HOURS constant, a colon and two digits of a clock minute, and nothing else, and MUST return None for any other value.
_parse_exif_moment: [VALIDATION_ERROR] MUST return None unless text is a string that, after trailing NUL characters and spaces are removed, is exactly a valid calendar date and time written YYYY:MM:DD HH:MM:SS; that local time MUST be read at the offset _camera_offset gives for offset, or, when it gives None, in zone with fold zero, so a time that occurs twice is its first occurrence and a time that does not exist takes the offset in force before the change, and turned into UTC by _to_naive_utc; it MUST return None when the UTC year is before the imported CAMERA_EARLIEST_YEAR constant or the moment lies more than the imported CAMERA_LATEST_AFTER_MODIFIED_HOURS constant of hours after modified, and the moment otherwise.
prepare_photo: [VALIDATION_ERROR] MUST open raw with Image.open restricted to the formats of the imported SOURCE_FORMATS constant; a source is opened when Image.open returns and the width and height of its first frame are read, and any failure before that, a DecompressionBombError of Image.open included, MUST raise Rejected with the UNREADABLE_IMAGE member of = models.PlacementFailure; for an opened source, before decoding pixels, it MUST raise Rejected with TOO_MANY_PIXELS when that width times that height is above the imported MAX_PIXELS constant; a later failure to decode the first frame or of any operation of the first rule of A2 MUST raise Rejected with UNREADABLE_IMAGE, and an encoded result longer than the imported MAX_OUTPUT_BYTES constant Rejected with TOO_LARGE; a value equal to a limit passes.
prepare_photo: [BEHAVIOR] MUST make the image of the first frame by exactly the operations of the first rule of A2 in their order: ImageOps.exif_transpose, Image.convert to RGBA with no colour management, Image.thumbnail with a box of the imported PHOTO_MAX_SIDE constant on each side and Image.Resampling.LANCZOS, a paste with its own alpha as the mask onto a new RGB image of the same size filled with the imported PHOTO_BACKGROUND constant, and Image.save as JPEG with quality the imported PHOTO_QUALITY constant, optimize the imported PHOTO_OPTIMIZE constant, progressive the imported PHOTO_PROGRESSIVE constant and subsampling the imported PHOTO_SUBSAMPLING constant, and no EXIF, colour profile or other metadata; it MUST return a PreparedPhoto of those bytes and of the moment and date source _photo_moment gives for the opened source image, modified and the ZoneInfo of timezone_name.

## delivery_store

_sync_folder: [BEHAVIOR] MUST open the folder read-only as a folder, call os.fsync on that descriptor and close it on every path, letting any OSError pass to its caller.
_make_folders: [PATH_OR_ARTIFACT_POLICY] MUST make every folder from base down to folder exist, outermost first, creating only the folders on that path below base: base itself is used as it stands, also through a link; a folder found, created by any call of any process and whatever its mode, is accepted as it stands, and a creation that loses the race to another process is accepted when the entry is then a folder; a folder this call creates takes mode by os.chmod after os.mkdir, so the umask does not change it; an entry on the path that is a symbolic link or not a folder, checked without following a link, MUST raise OSError. When durable is true, each folder this call creates MUST be synchronised in its parent with _sync_folder before the next one is made. It removes nothing.
_atomic_write: [PATH_OR_ARTIFACT_POLICY] MUST call _make_folders for the folder of path below base with folder_mode and durable_folder, creating only the folders of this address and nothing ahead of use, then create a temporary file in that folder whose name is the imported TEMPORARY_NAME_PREFIX constant followed by a fresh name from secrets, exclusively and without following a link with the imported TEMPORARY_FILE_MODE constant, passing over a name that is taken and trying a fresh one; it MUST write all of content, set mode on the open file, os.fsync it, close it and os.replace it over path, so an existing file at path is never absent to a reader. When durable_folder is true it MUST then synchronise the folder of path with _sync_folder and any failure fails the write; when it is false that folder is synchronised after the rename and a failure there is neither raised nor undoes the file in place. A failure before the rename MUST remove the temporary file, leave it when that removal fails too, and raise the original OSError; a temporary file a crash leaves stays and is never read.
_state_unavailable: [RETURN_SHAPE] MUST return, not raise, a DelivererError with the STATE_UNAVAILABLE member of = models.RefusalCode for the given error, so its caller raises it from that error.
_read_record: [VALIDATION_ERROR] MUST open the state folder, the third folder above path, as it stands, also through a link, then each of the two folders below it in the one before through dir_fd as a folder without following a link, then the record file in the last of them for reading only, in non-blocking mode and without following a link, and MUST return None only when a folder on that path or the record file does not exist; a folder on the path that is a link or not a folder, a record that is a link or not a regular file by os.fstat of the opened descriptor, a failed opening or reading, content that is not UTF-8 JSON valid against model with no extra field, or a record whose project_id and source_id differ from the given ones MUST raise the DelivererError _state_unavailable returns; otherwise it MUST return the validated record. Every descriptor is closed on every path and nothing is written.
_write_record: [ORCHESTRATION] MUST serialise record as its UTF-8 JSON form, every datetime written naive in UTC by isoformat, and write it with _atomic_write at path below base with the imported RECORD_MODE constant, the imported STATE_FOLDER_MODE constant for folders and durable_folder false, letting its OSError pass.
_placement_path: [PATH_OR_ARTIFACT_POLICY] MUST return the state_dir of context joined with the imported PLACEMENTS_FOLDER constant, the canonical lowercase hyphenated project id as one folder and the source id followed by the imported RECORD_FILE_SUFFIX constant as the file name; no other received text becomes part of the path.
_mark_path: [PATH_OR_ARTIFACT_POLICY] MUST return the state_dir of context joined with the imported MARKS_FOLDER constant, the canonical lowercase hyphenated project id as one folder and the source id followed by the imported RECORD_FILE_SUFFIX constant as the file name; no other received text becomes part of the path.
_store_path: [PATH_OR_ARTIFACT_POLICY] MUST resolve the binary_root of context strictly, join the file_ref to that resolved root and resolve the result without requiring it to exist, so the part that exists is resolved following its links and the parts not yet created are joined as named, and MUST return that path only when it lies strictly below the resolved root; a path outside it, a loop of links or any OSError or RuntimeError of resolving MUST raise DelivererError with the UNSAFE_REFERENCE member of = models.RefusalCode before any folder or temporary file is created, so that refusal leaves the store as it was.
project_lock: [BEHAVIOR] MUST be a contextlib.contextmanager generator that makes the folder of the imported LOCKS_FOLDER constant exist below the state_dir of context with _make_folders, the imported STATE_FOLDER_MODE constant and durable false, then creates the lock file named by the canonical project id followed by the imported LOCK_FILE_SUFFIX constant exclusively, without following a link, with the imported LOCK_FILE_MODE constant, or, when it exists, opens it as it stands without following a link; it MUST take fcntl.flock with LOCK_EX on that descriptor, waiting without a time limit and with no retry of its own, yield once while holding it, and release and close it on every exit. Neither the lock file nor its folder is synchronised, a lock found partly created is completed and nothing created is removed.
project_lock: [VALIDATION_ERROR] An entry at the lock address that is a link or not a regular file by os.fstat, and any failure to make the folder, open the file or take the lock other than waiting for another holder, MUST raise the DelivererError _state_unavailable returns, before the caller's block runs.
read_placement: [ORCHESTRATION] MUST return what _read_record gives for _placement_path of the project id and source id with the PhotoPlacement model, None when the record does not exist, letting its DelivererError pass.
read_mark: [ORCHESTRATION] MUST return what _read_record gives for _mark_path of the project id and source id with the PublicationMark model, None when the record does not exist, letting its DelivererError pass.
write_placement: [ORCHESTRATION] MUST write placement with _write_record at _placement_path of its own project_id and source_id below the state_dir of context, so the address and the record cannot disagree, and MUST let its OSError pass for the caller to turn into the failure of that photo.
write_mark: [VALIDATION_ERROR] MUST write mark with _write_record at _mark_path of its own project_id and source_id below the state_dir of context and MUST raise the DelivererError _state_unavailable returns from any OSError of that write, so a mark that cannot be written is refused.
store_image: [PATH_OR_ARTIFACT_POLICY] MUST build the reference from the imported STORED_IMAGES_FOLDER constant, the canonical lowercase hyphenated project id and the source id followed by the imported STORED_IMAGE_SUFFIX constant, joined by slashes, take its path from _store_path before anything is written, write content there with _atomic_write below the resolved binary_root of context with the imported STORED_IMAGE_MODE constant, the imported STORE_FOLDER_MODE constant for folders and durable_folder true, and return the reference; a DelivererError of _store_path and an OSError of the write MUST pass to the caller.

## photo_delivery

_require_source_id: [VALIDATION_ERROR] MUST return None only when the whole source id matches the imported SOURCE_ID_PATTERN constant with re.fullmatch, and MUST raise DelivererError with the INVALID_SOURCE_ID member of = models.RefusalCode otherwise; the source id never becomes part of a path before this check.
_photo_folder: [ORCHESTRATION] MUST call the imported confirmed_connection once with the connections_file of context and the project id, then the imported available_photo_folder with that connection, and return the folder it gives, letting each DelivererError pass; the connections file is read only there.
_observation: [FIELD_PROJECTION] MUST copy name, size, source_id, status and reason of a rejected source into a SourcePhotoObservation with no file_ref and no photo_id and read no record for it; for a ready source it MUST call read_placement and then read_mark for the project id and its source_id and return the PUBLISHED member of = models.ScanStatus with the file_ref of the placement and the photo_id of the mark when both exist, the PLACED member with that file_ref and no photo_id when only the placement exists, and the READY member with neither otherwise, letting their DelivererError pass.
scan_project_photos: [ORCHESTRATION] MUST call _photo_folder, then the imported observe_source_files on that folder, then _observation for each SourceFile in the order observed, and return a ScanResult of the project id, those observations in that order and, in counts, the number of observations of each = models.ScanStatus member that occurs, no member with zero; it takes no lock, reads no clock and writes nothing, and every DelivererError passes on whole, so no partial scan is answered.
_failed: [RETURN_SHAPE] MUST return a PlacementOutcome of the source id with the FAILED member of = models.PlacementStatus, the given reason, no placement and no photo_id.
deliver_project_photo: [ORCHESTRATION] MUST run these steps in this order, letting every DelivererError pass as the refusal of the whole request: _photo_folder; _require_source_id; then, inside the imported project_lock, which is released whenever it returns, call read_placement and then read_mark for the project id and source id before anything else, so a damaged record stops the delivery. An existing placement MUST be answered with the REPLAYED member of = models.PlacementStatus, that placement and the photo_id of the mark when one exists, writing nothing and reading no source file whatever the name.
deliver_project_photo: [VALIDATION_ERROR] Without a placement it MUST call the imported read_named_source once with the photo folder and the name and answer with _failed: the NOT_READY_OR_ABSENT member of = models.PlacementFailure when it returns None; for a rejected SourceFile, the PlacementFailure member whose value equals its reason; the SOURCE_CHANGED member when the hashlib.sha256 hexdigest of the bytes read differs from the source id; the reason of a Rejected that _place raises; and the UNREADABLE_FILE member when _place raises OSError; otherwise it MUST answer the PLACED member with the placement _place returns and no photo_id, leaving any existing mark as it is.
_mark_outcome: [FIELD_PROJECTION] MUST return a MarkOutcome holding the project_id, source_id, photo_id and marked_at of the mark unchanged and the given = models.MarkStatus member.
mark_photo_published: [ORCHESTRATION] MUST call _require_source_id, then read the imported utc_now exactly once, then the imported confirmed_connection with the connections_file of context and the project id, without consulting the photo folder, and then, inside the imported project_lock, which is released whenever it returns, call read_placement and then read_mark for the project id and source id, letting every DelivererError pass.
mark_photo_published: [VALIDATION_ERROR] Without a placement it MUST raise DelivererError with the NOT_PLACED member of = models.RefusalCode; a mark with the same photo_id MUST be answered by _mark_outcome with the REPLAYED member of = models.MarkStatus and that first mark unchanged; a mark with another photo_id MUST raise DelivererError with the PUBLICATION_CONFLICT member; without a mark it MUST write a PublicationMark of the project id, source id, photo_id and the time read from utc_now with the imported write_mark and answer _mark_outcome with the MARKED member. A refused or replayed mark writes nothing.
_place: [FIELD_ASSIGNMENT] MUST call the imported prepare_photo with raw, the modified of source and the timezone of context, then the imported store_image with its content, then the imported build_publication, and write with the imported write_placement a PhotoPlacement of the project id and source id, the name of source, the reference store_image returned, the hashlib.sha256 hexdigest and the length of the stored bytes, the imported STORED_MEDIA_TYPE constant as media_type, the date_source of the prepared photo and the publication, returning that placement; an exception raised by any of these calls MUST pass to the caller unchanged.
