# State 7 — Portal Deliverer notes

## deliverer_api

check_token: [SECURITY_BOUNDARY] MUST compare the presented credential with the service token whole and case-sensitively in constant time, so the time taken does not depend on where they differ, return None when they are equal, and raise AuthenticationRejected otherwise; a matching token authorizes the one principal of the service, the calling flow of the owner, for every confirmed connection, and it MUST NOT log or return either value.
parse_project_id: [VALIDATION_ERROR] MUST return the UUID the text spells only when the text is the canonical spelling of that UUID, lowercase hexadecimal digits in groups joined by hyphens exactly as str of the parsed UUID writes it, and MUST raise DelivererError with the INVALID_REQUEST member of = models.RefusalCode for any other text, including an uppercase, braced, URN or unhyphenated spelling.
_refusal_row: [BEHAVIOR] MUST return the one row of the imported REFUSAL_ANSWERS constant whose code equals the given = models.RefusalCode member; the table is total, so every member has exactly one row.
refusal_answer: [RETURN_SHAPE] MUST answer with a JSONResponse whose status is the status of the row _refusal_row returns for the code and whose body is the JSON form of a Refusal carrying that code and the detail of the same row, and nothing else.
answer_health: [RETURN_SHAPE] MUST return a HealthAnswer whose status is the OK member of = models.HealthStatus and nothing else; it reads no file, setting, token or project and raises nothing.

## runtime_settings

load_runtime_settings: [VALIDATION_ERROR] MUST read every variable of the runtime environment variable table once from the process environment, normalise it, apply the default its row declares for the environment field when it is absent and validate it exactly as its row declares, and return RuntimeSettings with each value in the field its row targets; a required variable that is absent or a value of the wrong form MUST raise ValueError that names the variable and never its value, and it MUST NOT read a file or log a raw value.

## deliverer_service

read_token: [SECURITY_BOUNDARY] MUST open the last component of path once without following a link, resolving the folders above it as they stand, and judge only that opened file: it MUST raise ValueError when the opening fails or meets a link, when the opened file is not a regular file, when its mode gives the group or others any permission, when its content does not decode in the encoding of the imported TOKEN_ENCODING constant, or when what remains after removing the characters of the imported TOKEN_TRIM_CHARACTERS constant at both ends, and no other character, is shorter than the imported TOKEN_MIN_LENGTH constant or holds a character outside the imported TOKEN_ALPHABET constant; otherwise it MUST return that remaining text. No message, log line or exception it raises MAY carry the content of the file.
load_config: [VALIDATION_ERROR] MUST raise ValueError when the port of the settings is one TCP cannot address or when the time zone database does not know their timezone, then MUST call the imported load_connections once with the connections_file of the settings as a Path, letting its DelivererError end the start, and MUST return DeliveryContext with binary_root, state_dir and connections_file of the settings as Path values and their timezone unchanged; it MUST NOT read the credential file.
run_service: [ORCHESTRATION] MUST call load_runtime_settings, then load_config with those settings, then read_token with the credential_file of the settings as a Path, then the imported create_app with that context and token, in that order, and serve the application with the imported uvicorn on the host of the imported BIND_HOST constant and the port of the settings, trusting no forwarded or proxy header. It MUST return the status of the row of the imported EXIT_STATUSES constant for the way the process ends: for the START_FAILED member of = models.ServiceExit when any step fails or a signal ends it before the web server listens, after writing one line naming the step that failed or was interrupted to standard error and never the token; for the SERVED member of = models.ServiceExit when its web server returns without an error after a signal of the imported STOP_SIGNALS constant stopped it; and for the SERVER_FAILED member of = models.ServiceExit for any other end after the web server has begun listening.

## object_connections

_subfolder: [VALIDATION_ERROR] MUST return the value unchanged only when it is a string holding a relative path whose written segments, taken as written, name a folder strictly below the root without ever leaving it or naming the root itself, and MUST raise ValueError for any other value.
confirmed_connection: [VALIDATION_ERROR] MUST call load_connections exactly once with connections_file and decide only from that reading, in this order: its DelivererError passes on unchanged; a reading with no record for project_id MUST raise DelivererError with the UNKNOWN_PROJECT member of = models.RefusalCode; a record whose assignment_confirmed is false MUST raise DelivererError with the CONNECTION_NOT_CONFIRMED member of = models.RefusalCode; otherwise it MUST return that ObjectConnection. It MUST NOT consult any folder.
available_photo_folder: [PATH_OR_ARTIFACT_POLICY] MUST return the photo folder of the connection, resolved through every link, only when the root of the connection and that folder both exist as folders and the folder lies strictly below the resolved root; a missing root or folder, one that is not a folder, a loop of links, any failure to resolve or inspect them, or a photo folder equal to or outside the resolved root MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode. It MUST NOT list the folder or touch the invoice_subfolder.
_connections_file: [VALIDATION_ERROR] MUST return content validated strictly against = models.ConnectionsFile only when it is one JSON text in the encoding the JSON standard requires, in which no object repeats a member name, whose only member is objects, each key of objects the canonical lowercase hyphenated spelling of a UUID, and each value a ConnectionEntry with exactly its fields, each of its declared type without coercion; it MUST raise ValueError for any other content.
load_connections: [VALIDATION_ERROR] MUST read the file at path once and judge it whole before any project is looked up: a file that is absent or cannot be read, a ValueError of _connections_file for its bytes, or a ValueError of _subfolder for the photo_subfolder or invoice_subfolder of any entry MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode; otherwise it MUST return a dict from the UUID of each key to an ObjectConnection with that project_id and the fields of its ConnectionEntry.

## source_folder

_is_ignored: [PATH_OR_ARTIFACT_POLICY] MUST return True when the name begins with an item of the imported IGNORED_NAME_PREFIXES constant, ends with an item of the imported IGNORED_NAME_SUFFIXES constant, or contains the imported CONFLICT_COPY_MARK constant, comparing the case of the ASCII letters only and every other character exactly, and False otherwise.
_opened_folder: [PATH_OR_ARTIFACT_POLICY] MUST be a context manager that yields an open descriptor of the folder at the absolute path, reached from the root of the file system one folder at a time, each opened as a folder relative to the one before it without following a symbolic link, and MUST close every descriptor it opened on every exit; a failure to open any of them, a symbolic link or an object that is not a folder among them, MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode.
_unlisted_folder: [VALIDATION_ERROR] MUST raise DelivererError with the FOLDER_UNAVAILABLE member of = models.RefusalCode chained from the given OSError and MUST never return; it is the one place a folder that cannot be listed or opened during a scan becomes a refusal.
_modified_at: [RETURN_SHAPE] MUST return the modification time of info, taken in whole nanoseconds, as a naive datetime in UTC with microsecond precision, truncating any finer fraction toward the earlier instant, also before the epoch; it MUST NOT pass through a floating-point time or the local time zone.
_read_source_bytes: [VALIDATION_ERROR] MUST open entry once, relative to the folder descriptor, for reading only, without blocking and without following a link, and judge the opened object before reading it: one that is not a regular file MUST raise Rejected with the NOT_A_REGULAR_FILE member of = models.PlacementFailure, and a failure to open, inspect or read it MUST raise Rejected with the UNREADABLE_FILE member. It MUST read from the start until the end of the file or one byte past the imported MAX_SOURCE_BYTES constant, whichever comes first, raise Rejected with the TOO_LARGE member when that byte is reached, and otherwise return every byte read together with the status of the opened file taken before reading; the file MUST be closed on every path and never opened again.
_source_files: [DETERMINISM_OR_ORDERING] MUST yield, for each regular file below the folder descriptor, the descriptor of the folder holding it, its entry name, its name relative to the photo folder with its segments joined by the path separator of the operating system, and its status read without following a link; within each folder its regular files MUST come first in Unicode code point order of their entry names, then each subfolder in that order, walked the same way. It MUST list each folder once and skip every name _is_ignored accepts, every entry that disappears before its status is read, every entry that is neither a regular file nor a folder, and every subfolder found to be a symbolic link or not a folder when it is opened; a subfolder is opened relative to its parent without following a link and closed when its walk ends, and any other failure to list a folder, read a status or open a subfolder MUST be handed to _unlisted_folder.
observe_source_files: [ORCHESTRATION] MUST open the folder with _opened_folder, call _observed once for each file _source_files yields from that descriptor, and return the SourceFile of each in the order _source_files yields them, keeping no bytes; a DelivererError of the walk MUST pass on, so a partial scan is never returned, and it MUST NOT create, change, move or delete anything in the folder.
_name_parts: [VALIDATION_ERROR] MUST return the segments of the name, split on the path separator of the operating system, only when the name is non-empty and relative and no segment is empty, names the current or the parent folder, or is one _is_ignored accepts, comparing exactly without Unicode normalisation, and MUST return None for any other name.
read_named_source: [PATH_OR_ARTIFACT_POLICY] MUST return None, opening nothing in the folder, when _name_parts returns None. Otherwise it MUST reach the named file from the folder _opened_folder opens through each folder segment of the name, each opened relative to the one before it without following a symbolic link, and read the status of the last segment without following a link; it MUST return None when an opening or that reading fails, the DelivererError of _opened_folder among them, or the last segment is not a regular file, and otherwise a SourceRead holding the SourceFile and bytes _observed gives for that last segment, its folder descriptor, the name and that status. Every descriptor it opened MUST be closed before it returns.
_signature_format: [BEHAVIOR] MUST return the first format of the imported SOURCE_FORMATS constant, in its order, for which every row of the imported SOURCE_SIGNATURES constant whose format equals it finds the bytes its signature spells in hexadecimal at its offset from the start of content, and None when no format does; it reads only content.
_observed: [VALIDATION_ERROR] MUST judge the rejection orders of A1 in their order: a file whose listed size in info says it holds no byte is rejected with the EMPTY member of = models.ObservationReason and one whose listed size is above the imported MAX_SOURCE_BYTES constant with the TOO_LARGE member, both before the file is opened; then it MUST call _read_source_bytes once, and a Rejected it raises is rejected with the reason of the row of the imported OBSERVATION_FAILURES constant whose failure is its reason, no bytes read with the EMPTY member and _signature_format returning None with the UNSUPPORTED_FORMAT member. A rejected SourceFile carries the REJECTED member of = models.ScanStatus, the given name, the listed size, the time _modified_at gives for info, no source id and no bytes; otherwise it MUST return a SourceFile with the READY member of = models.ScanStatus, the lowercase hexadecimal digest of the imported sha256 of the bytes as source_id, their length as size and the time _modified_at gives for the status of the read, together with those bytes.

## photo_preparation

_to_naive_utc: [RETURN_SHAPE] MUST return the same instant as the given aware datetime in UTC without a time zone, keeping its microseconds, and MUST raise ValueError for a naive datetime, which names no instant.
_photo_moment: [BEHAVIOR] MUST read the EXIF of the first frame of image once, a reading that fails counting as no EXIF, giving each tag value to _parse_exif_moment only when it is a string and None otherwise, and return the first moment _parse_exif_moment gives, judged against modified and read in zone, for the EXIF DateTimeOriginal tag of the Exif directory with its OffsetTimeOriginal tag, then for the EXIF DateTime tag of the first directory with no offset, paired with the EXIF member of = models.DateSource; when neither gives one it MUST return modified unchanged with the FILE_MODIFIED member of = models.DateSource. It MUST NOT read the service clock.
build_publication: [FIELD_ASSIGNMENT] MUST return a PhotoPublication whose intake_id is the imported INTAKE_ID_PREFIX constant followed by the canonical project id, the imported INTAKE_ID_SEPARATOR constant and the source id, whose project_id and file_ref are the given ones, whose photo_date is the taken_at of photo unchanged, whose intake_source is the imported INTAKE_SOURCE constant, whose client_visible is false and whose section_id and caption are None; it reads nothing and writes nothing.
_camera_offset: [VALIDATION_ERROR] MUST return the fixed time zone of the offset only when it matches the pattern of the imported EXIF_OFFSET_PATTERN constant whole, whose hours are not above the imported CAMERA_OFFSET_MAX_HOURS constant and whose minutes are a clock minute, and MUST return None for any other value.
_parse_exif_moment: [VALIDATION_ERROR] MUST return None unless text, once its trailing NUL characters and spaces are removed, matches the pattern of the imported EXIF_DATETIME_PATTERN constant whole and is a valid calendar date and time; that local time MUST be read at the offset _camera_offset gives for offset, or, when it gives None, in zone taking the first occurrence of a time that occurs twice and the offset in force before the change for a time that does not exist, and turned into UTC by _to_naive_utc; it MUST return None when the UTC year is before the imported CAMERA_EARLIEST_YEAR constant or the moment lies more than the imported CAMERA_LATEST_AFTER_MODIFIED_HOURS constant of hours after modified, and the moment otherwise.
prepare_photo: [VALIDATION_ERROR] MUST open raw with the image library's open, restricted to the formats of the imported SOURCE_FORMATS constant; a source is opened when that open returns and the size of its first frame is read, and any failure before that, the library's decompression-bomb error included, MUST raise Rejected with the UNREADABLE_IMAGE member of = models.PlacementFailure. For an opened source it MUST, before decoding pixels, raise Rejected with the TOO_MANY_PIXELS member of = models.PlacementFailure when its first frame holds more pixels than the imported MAX_PIXELS constant; a later failure to decode the first frame or of any operation of the first rule of A2 MUST raise Rejected with the UNREADABLE_IMAGE member, and an encoded result longer than the imported MAX_OUTPUT_BYTES constant Rejected with the TOO_LARGE member; a value equal to a limit passes.
prepare_photo: [BEHAVIOR] MUST make the stored image from the first frame by exactly the image-library operations the first rule of A2 decides, in its order: the library's EXIF transposition, its conversion to RGBA without colour management, its thumbnail reduction to a box of the imported PHOTO_MAX_SIDE constant on each side with its LANCZOS filter, a paste with the image's own alpha as the mask onto a new RGB image of the same size filled with the imported PHOTO_BACKGROUND constant, and its JPEG encoding whose quality is the imported PHOTO_QUALITY constant, whose optimize is the imported PHOTO_OPTIMIZE constant, whose progressive is the imported PHOTO_PROGRESSIVE constant and whose subsampling is the imported PHOTO_SUBSAMPLING constant, with no EXIF, colour profile or other metadata; it MUST return a PreparedPhoto of those bytes and of the moment and date source _photo_moment gives for the opened source image, modified and the time zone timezone_name names.

## delivery_store

_sync_folder: [BEHAVIOR] MUST make the entries of the folder durable on storage, opening it read-only as a folder for that and closing it on every path, and MUST let any OSError pass to its caller.
_make_folders: [PATH_OR_ARTIFACT_POLICY] MUST make every folder from base down to folder exist, outermost first, creating only the folders on that path below base: base itself is used as it stands, also through a link; a folder found, created by any call of any process and whatever its mode, is accepted as it stands, and a creation that loses the race to another process is accepted when the entry is then a folder; a folder this call creates MUST end with exactly mode, whatever the process umask; an entry on the path that is a symbolic link or not a folder, judged without following a link, MUST raise OSError. When durable is true, each folder this call creates MUST be made durable in its parent with _sync_folder before the next one is made. It removes nothing.
_atomic_write: [PATH_OR_ARTIFACT_POLICY] MUST make the folder of path exist below base by calling _make_folders with folder_mode as its mode and durable_folder as its durable, creating only the folders of this address and nothing ahead of use, then write content to a fresh temporary file in that folder whose name is the imported TEMPORARY_NAME_PREFIX constant followed by an unpredictable name, created exclusively, without following a link and with the imported TEMPORARY_FILE_MODE constant, a name already taken being passed over for another; the temporary file MUST hold all of content with mode, be durable on storage and closed before it atomically replaces path, so an existing file at path is never absent to a reader. When durable_folder is true the folder of path MUST then be made durable with _sync_folder and any failure fails the write; when it is false that folder is made durable after the replacement and a failure there is neither raised nor undoes the file in place. A failure before the replacement MUST remove the temporary file, leave it when that removal fails too, and raise the original OSError; a temporary file a crash leaves stays and is never read.
_state_unavailable: [RETURN_SHAPE] MUST return, not raise, a DelivererError with the STATE_UNAVAILABLE member of = models.RefusalCode for the given error, so its caller raises it from that error.
_read_record: [PATH_OR_ARTIFACT_POLICY] MUST reach the record from the state folder, the third folder above path, opened as it stands, also through a link, through the two folders below it, each opened relative to the one before without following a link, and open the record file in the last of them for reading only, without blocking and without following a link; it MUST return None only when a folder on that path or the record file does not exist. A folder on the path that is a link or not a folder, a record that is a link or not a regular file, or a failed opening or reading MUST raise the DelivererError _state_unavailable returns; otherwise it MUST return every byte of the record. Everything it opened is closed on every path and nothing is written.
_write_record: [ORCHESTRATION] MUST write the JSON form the model of record gives, every datetime in it naive in UTC, with _atomic_write at path below base with the imported RECORD_MODE constant, the imported STATE_FOLDER_MODE constant for folders and durable_folder false, letting its OSError pass.
_placement_path: [PATH_OR_ARTIFACT_POLICY] MUST return the state_dir of context joined with the imported PLACEMENTS_FOLDER constant, the canonical lowercase hyphenated project id as one folder and the source id followed by the imported RECORD_FILE_SUFFIX constant as the file name; no other received text becomes part of the path.
_mark_path: [PATH_OR_ARTIFACT_POLICY] MUST return the state_dir of context joined with the imported MARKS_FOLDER constant, the canonical lowercase hyphenated project id as one folder and the source id followed by the imported RECORD_FILE_SUFFIX constant as the file name; no other received text becomes part of the path.
_store_path: [PATH_OR_ARTIFACT_POLICY] MUST return the path file_ref names below the binary_root of context, resolved through every link of the part that exists while the parts not yet created are taken as named, only when it lies strictly below the resolved root; a path outside it, a loop of links or any failure to resolve MUST raise DelivererError with the UNSAFE_REFERENCE member of = models.RefusalCode before any folder or temporary file is created, so that refusal leaves the store as it was.
project_lock: [BEHAVIOR] MUST be a context manager that holds the exclusive operating-system lock of the project's lock file for the whole of the caller's block, waiting for another holder without a time limit and with no retry of its own, and releases and closes it on every exit. The lock file MUST be named by the canonical project id followed by the imported LOCK_FILE_SUFFIX constant in the folder of the imported LOCKS_FOLDER constant below the state_dir of context, which it makes exist with _make_folders, the imported STATE_FOLDER_MODE constant and durable false; it is created exclusively, without following a link, with the imported LOCK_FILE_MODE constant, or, when it exists, opened as it stands without following a link. Neither the lock file nor its folder is made durable, a lock found partly created is completed and nothing created is removed.
project_lock: [VALIDATION_ERROR] An entry at the lock address that is a link or not a regular file, and any failure to make the folder, open the file or take the lock other than waiting for another holder, MUST raise the DelivererError _state_unavailable returns, before the caller's block runs.
read_placement: [VALIDATION_ERROR] MUST return None when _read_record gives None for _placement_path of the project id and source id, letting its DelivererError pass; otherwise it MUST return the PhotoPlacement those bytes hold only when they are one JSON text in the encoding the JSON standard requires, valid against = models.PhotoPlacement with no extra field, whose project_id and source_id are the given ones, and MUST raise the DelivererError _state_unavailable returns for any other content.
read_mark: [VALIDATION_ERROR] MUST return None when _read_record gives None for _mark_path of the project id and source id, letting its DelivererError pass; otherwise it MUST return the PublicationMark those bytes hold only when they are one JSON text in the encoding the JSON standard requires, valid against = models.PublicationMark with no extra field, whose project_id and source_id are the given ones, and MUST raise the DelivererError _state_unavailable returns for any other content.
write_placement: [ORCHESTRATION] MUST write placement with _write_record at _placement_path of its own project_id and source_id below the state_dir of context, so the address and the record cannot disagree, and MUST let its OSError pass for the caller to turn into the failure of that photo.
write_mark: [VALIDATION_ERROR] MUST write mark with _write_record at _mark_path of its own project_id and source_id below the state_dir of context and MUST raise the DelivererError _state_unavailable returns from any OSError of that write, so a mark that cannot be written is refused.
store_image: [PATH_OR_ARTIFACT_POLICY] MUST build the reference as the relative Portal file reference whose segments are the imported STORED_IMAGES_FOLDER constant, the canonical lowercase hyphenated project id and the source id followed by the imported STORED_IMAGE_SUFFIX constant, take its path from _store_path before anything is written, write content there with _atomic_write below the resolved binary_root of context with the imported STORED_IMAGE_MODE constant, the imported STORE_FOLDER_MODE constant for folders and durable_folder true, and return the reference; a DelivererError of _store_path and an OSError of the write MUST pass to the caller.

## photo_delivery

_require_source_id: [VALIDATION_ERROR] MUST return None only when the whole source id, from its first character to its last, matches the pattern of the imported SOURCE_ID_PATTERN constant, and MUST raise DelivererError with the INVALID_SOURCE_ID member of = models.RefusalCode otherwise; the source id never becomes part of a path before this check.
_photo_folder: [ORCHESTRATION] MUST call the imported confirmed_connection once with the connections_file of context and the project id, then the imported available_photo_folder with that connection, and return the folder it gives, letting each DelivererError pass; it is the one reading of the connections file in a scan or a delivery.
_observation: [FIELD_PROJECTION] MUST copy name, size, source_id, status and reason of a source whose status is the REJECTED member of = models.ScanStatus into a SourcePhotoObservation with no file_ref and no photo_id and read no record for it; for a source whose status is the READY member, which observe_source_files always gives a source id, it MUST call read_placement and then read_mark for the project id and that source_id and return the PUBLISHED member of = models.ScanStatus with the file_ref of the placement and the photo_id of the mark when both exist, the PLACED member with that file_ref and no photo_id when only the placement exists, and the READY member with neither otherwise, letting their DelivererError pass.
scan_project_photos: [ORCHESTRATION] MUST call _photo_folder, then the imported observe_source_files on that folder, then _observation for each SourceFile in the order observed, and return a ScanResult of the project id, those observations in that order and, in counts, the number of observations of each = models.ScanStatus member that occurs, no member with zero; it takes no lock, reads no clock and writes nothing, and every DelivererError passes on whole, so no partial scan is answered.
_failed: [RETURN_SHAPE] MUST return a PlacementOutcome of the source id with the FAILED member of = models.PlacementStatus, the given reason, no placement and no photo_id.
deliver_project_photo: [ORCHESTRATION] MUST run these steps in this order, letting every DelivererError pass as the refusal of the whole request: _photo_folder; _require_source_id; then, inside the imported project_lock, which is released whenever it returns, call read_placement and then read_mark for the project id and source id before anything else, so a damaged record stops the delivery. An existing placement MUST be answered with the REPLAYED member of = models.PlacementStatus, that placement and the photo_id of the mark when one exists, writing nothing and reading no source file whatever the name.
deliver_project_photo: [VALIDATION_ERROR] Without a placement it MUST call the imported read_named_source once with the photo folder and the name and answer with _failed: the NOT_READY_OR_ABSENT member of = models.PlacementFailure when it returns None; for a SourceFile whose status is the REJECTED member of = models.ScanStatus, which read_named_source always gives a reason, the failure of the row of the imported OBSERVATION_FAILURES constant whose reason is that reason; the SOURCE_CHANGED member when the lowercase hexadecimal digest of the imported sha256 of the bytes read differs from the source id; the reason of a Rejected that _place raises; and the UNREADABLE_FILE member when _place raises OSError; otherwise it MUST answer the PLACED member with the placement _place returns and no photo_id, leaving any existing mark as it is.
_mark_outcome: [FIELD_PROJECTION] MUST return a MarkOutcome holding the project_id, source_id, photo_id and marked_at of the mark unchanged and the given = models.MarkStatus member.
mark_photo_published: [ORCHESTRATION] MUST call _require_source_id, then read the imported utc_now exactly once, then the imported confirmed_connection with the connections_file of context and the project id, without consulting the photo folder, and then, inside the imported project_lock, which is released whenever it returns, call read_placement and then read_mark for the project id and source id, letting every DelivererError pass.
mark_photo_published: [VALIDATION_ERROR] Without a placement it MUST raise DelivererError with the NOT_PLACED member of = models.RefusalCode; a mark with the same photo_id MUST be answered by _mark_outcome with the REPLAYED member of = models.MarkStatus and that first mark unchanged; a mark with another photo_id MUST raise DelivererError with the PUBLICATION_CONFLICT member; without a mark it MUST write a PublicationMark of the project id, source id, photo_id and the time read from utc_now with the imported write_mark and answer _mark_outcome with the MARKED member. A refused or replayed mark writes nothing.
_place: [FIELD_ASSIGNMENT] MUST call the imported prepare_photo with raw, the modified of source and the timezone of context, then the imported store_image with its content, then the imported build_publication, and write with the imported write_placement a PhotoPlacement of the project id and source id, the name of source, the reference store_image returned, the lowercase hexadecimal digest of the imported sha256 of the stored bytes and their length, the imported STORED_MEDIA_TYPE constant as media_type, the date_source of the prepared photo and the publication, returning that placement; an exception raised by any of these calls MUST pass to the caller unchanged.

## refusals

DelivererError.__init__: [FIELD_ASSIGNMENT] MUST set its code field to the RefusalCode member it is given, unchanged, so that a caller answers the refusal from that field alone.
Rejected.__init__: [FIELD_ASSIGNMENT] MUST set its reason field to the PlacementFailure member it is given, unchanged, so that the failure of that photo is read from that field alone.
