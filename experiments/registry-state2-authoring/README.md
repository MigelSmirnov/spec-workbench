# Registry State 2 — расследование в процессе авторства

Продолжение `experiments/registry-state2-investigation/`. Там восстанавливались
известные исторические дефекты, здесь взят открытый вопрос State 2, на который
ответ ещё не подготовлен: **что получает запрос, который указывает ревизию для
записи без ревизии** — стёртого клиента или анонимизированного проекта.
Главный случай — повторная отправка формы стирания после потерянного ответа.

Итоги — в [`REPORT.md`](REPORT.md). Вопрос владельцу — в
[`OWNER_QUESTION.md`](OWNER_QUESTION.md).

Канонические тексты Registry и общие инструменты не менялись. Правки лежат
только в `patch/`.
